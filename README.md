# Aureon — VIP & Fancy Mobile Numbers

A furnished boutique for VIP, fancy, and numerology mobile numbers, designed in the spirit of [Lifetime Number](https://www.lifetimenumber.com/) — light fashion-house layout, cream and azure, editorial type — with catalogue depth from Numbers Point, Number ATM, and operator choice-number flows.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s inside

- Global / premium / advanced digit search, price search, family pack
- Numerology total & destiny filters, without 2-4-8
- VIP catalogue with VVIP, mirror, penta, hexa, 786, doubling, pre-book
- Bag, wishlist, demo checkout with UPC
- Offer zone, pre-booking, journal, gallery, desk, legal pages

Demo only: cart and accounts live in the browser. No live payments or MNP.
